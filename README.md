# 威尔阳 WEIERYANG 面试测评

GitHub Pages 静态前端与 Firebase Spark Realtime Database。候选人使用管理员生成的一次性邀请链接，无需注册或登录；HR 使用授权的邮箱和密码登录工作台。

- 管理入口：`admin.html`
- 候选人入口：管理员在「候选人邀请」中生成的链接，每份邀请仅能提交一次。
- 草稿保存在当前浏览器标签页；成功提交并取得云端回执后清除草稿。
- HR 打开工作台时按答卷绑定的规则版本自动评分并保存。Firebase 安全规则验证得分；不使用收费云函数。
- 线上评分规则保存在受保护的数据库。公共前端发布仓库不包含具体评分标准或候选人数据；私有源码备份的 `private/` 目录保留初始题库与数据库规则。
- 结果仅供人工面试参考，不自动决定录用。管理员可查看原始答案、备注、导出 CSV 和备份。

## 开发与构建

需要 Node.js 22.12 或更新版本。

```sh
npm ci
npm run dev
npm run build
```

公共前端仓库的 GitHub Pages 从 `main` 分支的 `docs/` 发布。私有源码备份不包含 `docs/`；后续代码更新后须重新构建，只将审核后的公开源码及构建产物同步到前端发布仓库。

`src/firebase-config.js` 是 Firebase Web 应用的公开配置，不是数据库管理凭据。访问权限由部署到 Firebase 的安全规则执行，切勿把数据库设为公开读写。

管理员身份同时绑定指定的 Firebase 用户 UID、邮箱和密码登录提供方。密码仅由 Firebase Authentication 管理，不写入源码、配置文件或构建产物。更换管理员须先创建对应账号，再同步 UID、邮箱和数据库安全规则；不能只修改页面显示的邮箱。

免费套餐有配额限制；网络可达性因地区与运营商而异。中国大陆候选人的完整答题与提交应通过真实设备验证。
